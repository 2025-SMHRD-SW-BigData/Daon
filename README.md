# 🐟 귀어로드 (GuiFish Road)

> 귀어귀촌 입문자를 위한 통합 정보 기반 어업 창업 지원 플랫폼  
> **"귀어로드"는 어촌 정착, 어업 창업, 정책 정보, 지역 커뮤니티 기능을 통합한 올인원 플랫폼입니다.**

---

## 📌 프로젝트 개요

- **프로젝트명**: 귀어로드 (GuiFish Road)
- **목표**: 귀어 창업을 희망하는 청년 및 도시민을 대상으로 입문부터 정착까지 필요한 정보를 통합 제공하는 디지털 플랫폼 개발
- **기간**: 2025.05.30 ~ 2025.07.07
- **팀명**: 다 온
- **참여 인원**: 4명

| 이름   | 역할 요약 |
|--------|------------|
| **구도진** | 팀장 / PM, 프론트엔드, 마이페이지, 메인 UI |
| **이진우** | 백엔드 전반, 챗봇 AI, 지도 API, 커뮤니티 기능 |
| **이하늘** | 프론트엔드, 데이터 수집, 커뮤니티 UI, 정책 페이지 |
| **최정운** | 백엔드, 기획서 작성, 회원가입, 정착상담사 기능 |

---

## 🧩 주요 기능

### ✅ 핵심 기능

- **AI 챗봇**  
  HyperCLOVA 기반 질의응답 챗봇으로 정책, 어업 정보 응답 제공
- **지도 기반 어촌 탐색**  
  네이버 지도 API 활용, 어촌 위치 시각화, 마커 표시, 지역별 정보 제공
- **커뮤니티 기능**  
  지역별 게시판, 전문 정착상담사 Q&A, 댓글 알림 기능
- **정책 정보 제공**  
  어업 지원금, 자격 요건, 장비 정보, 지역 인프라 등 통합 제공
- **즐겨찾기 및 알림**  
  마이페이지에서 관심 정보 저장 및 커뮤니티 알림 확인 가능
