# 🐟 귀어로드

 귀어귀촌 입문자를 위한 통합 정보 기반 어업 창업 지원 플랫폼  



## 📌 프로젝트 개요

- **프로젝트명**: 귀어로드
- **목표**: 귀어 창업을 희망하는 청년 및 도시민을 대상으로 입문부터 정착까지 필요한 정보를 통합 제공하는 디지털 플랫폼 개발
- **기간**: 2025.05.30 ~ 2025.07.07
- **팀명**: 다 온
- **참여 인원**: 4명

| 이름   | 역할 요약 |
|--------|------------|
| **구도진** | 팀장 / PM, ID/PW 찾기 구현, 마이페이지,닉네임 수정 구현, 어업자격, 테스트 및 유지보수 |
| **이진우** | 백엔드, 챗봇 구현, 지도 API, CRUD게시판 구현,댓글 알림 구현, 즐겨찾기 구현 |
| **이하늘** | 프론트엔드, 커뮤니티 UI, 정착지 후보 비교 구현, 뒤로가기 기능 구현, 로그인 애니메이션, 어선정보/지원금 및 정책 페이지 작성 |
| **최정운** | 회원가입 기능 구현, DB 설계 및 구현, UI/UX 설계, 정착 상담사 기능 구현, 계획서/PPT/영상 |

| 분야 | 기술 |
|------|------|

---

## 🧩 주요 기능

### ✅ 핵심 기능

- **AI 챗봇**  
  HyperCLOVA 기반 질의응답 챗봇으로 정책, 어업 정보 응답 제공
- **지도 기반 어촌 탐색**  
  네이버 지도 API 활용, 어항 위치 시각화, 마커 표시, 지역별 정보 제공
- **커뮤니티 기능**  
  지역별 게시판, 전문 정착상담사 Q&A, 댓글 알림 기능
- **정책 정보 제공**  
  어업 지원금, 자격 요건, 장비 정보, 지역 인프라 등 통합 제공
- **즐겨찾기 및 알림**  
  마이페이지에서 관심 정보 저장 및 커뮤니티 알림 확인 가능

---

## ✅ 기능별 개발 담당자

| 기능 | 담당자 |
|------|--------|
| **AI 챗봇 기능 (HyperCLOVA 연동)** | 이진우 |
| **지도 탐색 기능 (Naver 지도 API)** | 이진우 (API 연동), 이하늘 (UI/UX 적용) |
| **커뮤니티 게시판 / 댓글 알림** | 이진우 (백엔드), 이하늘 (프론트 UI) |
| **전문 정착 상담사 Q&A 게시판** | 최정운 (기획 및 백엔드), 구도진 (프론트 개발) |
| **정책/자격/어업 정보 제공 페이지** | 이하늘 (프론트 구현), 최정운 (데이터 수집 및 DB 정리) |
| **정착지 후보 비교 / 지역 인프라 시각화** | 이하늘 (지도 연동 UI), 구도진 (데이터 연결) |
| **회원가입 / 로그인 / 마이페이지** | 최정운 (회원가입 및 DB 설계), 구도진 (마이페이지 닉네임 수정 등) |
| **즐겨찾기 및 알림 기능** | 이진우 (기능 구현), 구도진 (마이페이지 연동) |
| **전체 UI/UX 설계 및 모바일 반응형 구현** | 이하늘 (메인 UI), 구도진 (반응형 구조 및 유지보수) |
| **DB 설계 및 통합 유지관리** | 이진우 & 최정운 (공동 설계 및 연결) |
